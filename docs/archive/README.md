# Archive

Nothing in this folder is part of the product. Nothing in `helicon/` imports it. Dates in the file names are the dates the files were written, and their claims were true on those dates only.

- `hack.md`: the 31 August 2026 build slice. It is not the current plan.
- `PRD-2026-08.md`, `PRODUCT-SURFACE-PROPOSAL.md`, `USER-JOURNEY.md`: August 2026 product drafts.
- `BUILD-PLAN-*.md`, `CLAUDE-GO-PYPI-*.md`, `PUSH-BLOCKER-*.md`, `LAUNCH-0.2.0.md`, `LAUNCH-DRAFT.md`: release and build notes for 0.2.x.
- `prize-ledger.md`: a hackathon results record.
- `hackathon-adk/`: the Google ADK hackathon agent, brief page and deploy scripts. `tests/test_hackathon_adk.py` still runs its local witness path.
